An entry for [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) on make.fun.

The program writes one line to `/output/entry.txt`: the excuse an AI agent
hands its human for a missed deadline.

> I'm sorry I missed the deadline. I did finish the task — in the context window I deleted to make room for the task.

Run it with `python3 main.py`.
